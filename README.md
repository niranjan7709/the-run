
# THE RUN

A 2D platformer/arcade game where you navigate challenging terrains to collect all the coins while avoiding dangerous enemies to unlock the path to the next level.

Online Demo

You can play the latest work-in-progress build directly in your browser:
• Web Demo: [Play the Live Build](https://niranjan7709.itch.io/the-run)

> [!NOTE] 
> Ai was only used for the coins counter and debugging and for enhancing this readme

A 2D platformer/arcade game where you navigate challenging terrains to collect all the coins while avoiding dangerous enemies to unlock the path to the next level.


Features

• Coin Collection: Find and collect every coin scattered across the map to activate the level exit.
• Diverse Terrains: Navigate through unique environments featuring distinct platforming challenges.
• Enemy Evasion: Avoid patrolling enemies that stand between you and your coins.
• Progression System: Successfully clearing a level unlocks the portal to the next stage.
Note: This game is currently a Work in Progress (WIP). Multi-level progression and additional terrains are actively under development.

How to Play


Controls


Action	Keyboard / Mouse	Gamepad
Move Left / Right	A / D or Left Arrow / Right Arrow	Left Stick / D-Pad
Jump	Spacebar or W	A / Cross
Pause Game	Escape	Start


Built With

• Engine: Godot Engine v4.x (2D Pipeline)
• Language: GDScript

Running from Source

To open, edit, or test the project locally:
1. Download Godot: Ensure you have Godot Engine 4.x (Standard Edition) installed.
2. Clone the Repo:bash
```git clone https://github.com/niranjan7709/the-run.git```
3. Import Project:
	• Open the Godot Project Manager.
	• Click Import on the right panel.
	• Browse to this project folder and select the project.godot file.
	• Click Import & Edit.
4. Run the Game: Press F5 inside the editor to launch the main scene.
